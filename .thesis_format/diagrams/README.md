## 渲染方法

| 后缀 | 工具 | 在线地址 |
|---|---|---|
| `.puml` | PlantUML | https://www.plantuml.com/plantuml |

1. 打开 https://www.plantuml.com/plantuml
2. 粘贴 `.puml` 文件内容
3. 右键渲染结果 → 另存为 PNG（建议宽度 15.5cm）
